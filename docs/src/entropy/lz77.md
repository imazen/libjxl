# LZ77

JPEG XL optionally applies LZ77 back-reference compression to entropy-coded token
streams. This is most effective for content with repeated patterns (text screenshots,
synthetic images, large flat regions).

## When LZ77 Is Used

LZ77 is applied to token streams after value encoding through `HybridUintConfig` but
before histogram construction. It replaces runs of repeated tokens with
length + distance pairs.

**Acceptance threshold**: LZ77 is only kept if it saves more than 20% of symbols
plus 16 bits:

```
if (bit_decrease > total_symbols * 0.2 + 16): accept
else: reject and use original tokens
```

## Three Strategies

### RLE (`kRLE`)

Simple run-length encoding of consecutive identical values:

- Scans for runs of repeated `value` at distance 1
- Cost estimate: `ceil(log2(len + 1)) + 1` bits for the reference
- If cheaper than raw symbols: emit LZ77 length + distance 0/1
- Fastest but only catches exact repetitions

### Greedy LZ77 (`kLZ77`)

Full backward-reference matching with hash chains:

```
for each position:
    walk hash chain (max 256 steps)
    find longest match (min_length threshold)
    lazy matching: also check position i+1
    if lz77_cost <= raw_cost: emit reference
```

**Hash chain**: XOR of 3 consecutive values with shift=5, masked to 15 bits.
Separate zero chain for O(1) skipping of zero-heavy regions. Window up to 1M entries.

**Cost model** uses hardcoded tables:

| Token | Length Cost (bits) |
|-------|-------------------|
| 0–8 | 2.4–4.5 |
| 9–16 | 9.2–13.8 |

Distance costs use a 131-entry table accounting for special 2D distance codes.

### Optimal LZ77 (`kOptimal`)

Dynamic programming for minimum-cost parsing:

1. Run greedy LZ77 as a preliminary pass (if rejected, skip optimal too)
2. Build `SymbolCostEstimator` from greedy output (histogram-based costs)
3. DP: `prefix_costs[i]` = minimum cost to encode first `i` symbols
4. For each position: try literal, try each match length/distance
5. Traceback to reconstruct optimal token sequence

**RLE skip**: Long constant runs (≥ 8 positions, match > 9 symbols) skip the
middle, processing only first 8 and last 8 positions. Prevents quadratic cost.

## LZ77 Parameters

```cpp
struct LZ77Params {
    bool enabled;
    uint32_t min_symbol;     // tokens >= this are LZ77 lengths
    uint32_t min_length;     // minimum match length
    HybridUintConfig length_uint_config;
};
```

`min_symbol` is set to 224 (ANS) or 512 (Huffman). This reserves a portion of the
token alphabet for LZ77 length codes.

## Special Distance Codes

120 WebP-style 2D distance codes encode small spatial offsets relative to
`distance_multiplier` (typically image width):

```
SpecialDistance(index, multiplier) = kSpecialDistances[index][0]
                                   + multiplier * kSpecialDistances[index][1]
```

"1 row up" = `distance_multiplier`, "1 row up, 1 left" = `distance_multiplier - 1`.
These encode 2D neighborhood references much cheaper than raw distances.

Distance codes ≥ 120 represent literal distances offset by `1 - kNumSpecialDistances`.

## SymbolCostEstimator

Provides per-symbol cost estimates for LZ77 decision-making:

```
cost[ctx][sym] = -log2(count / total)    // from histogram
                 or ANS_LOG_TAB_SIZE     // if symbol never seen
```

Includes a penalty for inserting LZ77 references into low-entropy contexts:
`add_symbol_cost = max(0, 6.0 - avg_bits_per_symbol)`. This prevents LZ77 from
polluting compact distributions where the overhead isn't justified.

## Speed Tier Gating

| Speed | LZ77 Method |
|-------|-------------|
| > Falcon (7) | `kNone` |
| Falcon (7)–Squirrel (3) | `kRLE` |
| Kitten (2) | `kLZ77` |
| Tortoise (1) | `kOptimal` |
